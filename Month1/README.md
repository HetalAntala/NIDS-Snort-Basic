# Network Intrusion Detection System (NIDS) Using Snort – Month 1

## 📌 Project Overview
This project focuses on building a **basic Network Intrusion Detection System (NIDS)** using **Snort**.  
The objective is to install, configure, and run Snort to monitor live network traffic and detect suspicious activities.

This project was completed as **Month-1 work of a 2-month Cybersecurity Internship**.

---

## 🎯 Problem Statement
To build and configure a working Network Intrusion Detection System using Snort that can:
- Monitor network traffic
- Detect suspicious activities
- Generate alerts for potential intrusions

---

## 🛠 Tools & Technologies Used
- Operating System: Ubuntu / Kali Linux
- IDS Tool: Snort
- Networking Tools: Ping
- Virtualization: VirtualBox / Hyper-V
- Language: Linux Shell Commands

---

## 📅 Month-1 Tasks Breakdown

### 🔹 Week 1: Installation & Setup
- Introduction to NIDS and Snort
- Installed Linux OS
- Installed and verified Snort
- Learned basic Linux commands

### 🔹 Week 2: Configuration & Monitoring
- Identified active network interface
- Configured Snort with monitored IP range
- Ran Snort in detection mode
- Monitored live network traffic

### 🔹 Week 3: Attack Simulation
- Simulated ICMP ping flood attack
- Observed and analyzed Snort alerts
- Studied alert formats and logs

### 🔹 Week 4: Rule Understanding
- Explored default Snort rules
- Learned Snort rule structure
- Documented configuration and alert behavior
