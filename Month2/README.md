# Advanced Network Intrusion Detection System Using Snort – Month 2

## 📌 Project Overview
This project extends the basic NIDS developed in Month-1 by implementing **advanced Snort configurations** including:
- Custom rule creation
- Detection of advanced attacks
- False positive reduction
- Alert tuning and optimization

This represents **Month-2 work of a 2-month Cybersecurity Internship**.

---

## 🎯 Problem Statement
To enhance the existing Snort-based NIDS by:
- Writing custom detection rules
- Detecting TCP scans and SSH attacks
- Reducing false positives
- Improving alert accuracy

---

## 🛠 Tools & Technologies Used
- Operating System: Ubuntu / Kali Linux
- IDS Tool: Snort
- Attack Tools: Nmap, Hydra (demo)
- Networking Tools: Ping
- Virtualization: VirtualBox / Hyper-V

---

## 📅 Month-2 Tasks Breakdown

### 🔹 Week 1: Custom Rule Development
- Studied in-depth Snort rule syntax
- Created custom ICMP, TCP, and SSH rules
- Integrated custom rules into Snort configuration

### 🔹 Week 2: Advanced Attack Simulation
- TCP SYN Port Scan using Nmap
- SSH Brute-Force simulation (controlled/demo)
- Verified alerts generated by custom rules

### 🔹 Week 3: False Positive Analysis
- Identified noisy alerts
- Tuned rules using threshold and suppression
- Reduced unnecessary alerts

### 🔹 Week 4: Final Analysis & Reporting
- Compiled detailed findings
- Compared alerts before and after tuning
- Prepared final documentation and screenshots
